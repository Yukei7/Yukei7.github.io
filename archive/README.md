# Archive

This folder stores the old generated Hexo site export that originally backed this repository.

## Contents

- `hexo-export/` contains the historical static HTML, CSS, JS, and assets.

## Notes

- This archive is kept for reference and recovery only.
- The active site is the Astro project under `src/` and `public/`.
- If migrated posts ever need to be regenerated, `scripts/extract_hexo_posts.py` reads from `archive/hexo-export/`.
